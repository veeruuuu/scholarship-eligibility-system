 🎓 Student Scholarship Eligibility Prediction System-

A full-stack web application that predicts student scholarship eligibility using a Hierarchical Fuzzy Inference System (Mamdani-style). Instead of a black-box score, the system produces a fully explainable result — showing exactly which factors and fuzzy rules drove the recommendation.
